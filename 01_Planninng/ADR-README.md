## ADR Format

Each ADR follows this structure:
1. **Problem Statement** — Why this decision was needed
2. **Decision** — What was decided
3. **Consequences** — Positive & negative implications
4. **Alternatives** — Other options considered & why rejected
5. **Compliance** — How to enforce this pattern
6. **References** — Related code/docs

## Contributing

When proposing a new ADR:
1. Create a new file: `ADR-NNN-Hyphenated-Title.md`
2. Use the template from ADR-001
3. Set status to `Proposed` initially
4. Circulate for team review
5. Update status to `Accepted` or `Rejected` after discussion
